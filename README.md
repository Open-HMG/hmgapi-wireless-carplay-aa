# Wireless CarPlay + Android Auto for HMG-API

The Wireless CarPlay + Android Auto mod for [HMG-API](https://github.com/Open-HMG/HMG-API),
the mod manager for Hyundai, Kia and Genesis Gen5W head units. It moved here from
HMG-API's `mods/wireless-carplay-aa`, with its history.
